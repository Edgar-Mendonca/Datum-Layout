# Where the catalogue comes from

Every part Datum Layout draws is **generated**: a shape rule in code (`crates/core/src/parts.rs`) plus a row of a dimension table here, plus ports. No 3D model is downloaded or bundled. Every table row carries its source in its `source` column; this file explains them.

| File | What it holds | Source |
| --- | --- | --- |
| `pipe.csv` | Nominal pipe sizes ½"–24": outside diameter and the wall of each schedule (inches) | The published nominal dimensions of wrought steel pipe (ASME B36.10M), as listed in Datum Pipe's library (`crates/core/src/library.rs` there) |
| `fittings.csv` | Butt-weld fittings: long- and short-radius elbow centre-to-end (90°), tee centre-to-end, reducer length, cap length | A manufacturer's public fitting catalogue, named on each row. Two values kept from the earlier table and noted on their rows: the ¾" long-radius elbow (1⅛" = 1.5 × NPS; the source row repeats the ½" value) and the ½" reducer length |
| `flanges.csv` | Weld-neck and blind flanges, class 150, 300, 600, 900, 1500 and 2500, ½"–24" where made: outside diameter, thickness, length through hub, raised-face diameter, number and size of studs, gasket thickness, and the blind's thickness where it differs (`blind_thick_in`) | Manufacturers' public flange data sheets and catalogue pages, named on each row |
| `valves.csv` | Flanged gate, globe, swing-check, ball and butterfly valves (triple offset, double flanged, short pattern, class 150–600, 3"–24": a manufacturer's table on wermac.org; its long-pattern lengths all equal the gate rows), class 150 to 2500: face-to-face length | Manufacturers' public valve catalogues, named on each row with page; rows not fully confirmed start with `UNVERIFIED:`. A size not listed is interpolated between its neighbours of the same kind and class |
| `tees_reducing.csv` | Butt-weld reducing tees, every run × branch listed ¾"–24": run centre-to-end (C) and branch centre-to-end (M) | Texas Flange's public reducing-tee tables (standard weight); every row to 4" also checked against wermac.org's ASME B16.9 table in millimetres (all agree) |
| `reducers.csv` | Butt-weld reducers, every large × small pair listed ¾"–24": end-to-end length (concentric and eccentric alike) | Texas Flange's public reducer tables (standard weight); 73 pairs checked against wermac.org's ASME B16.9 table (all agree), and the five 22" pairs taken from it |
| `olets.csv` | Weldolets (standard weight, size-on-size and reducing, ½"–24") and sockolets (class 3000, ½"–2"): height above the header (A), base and outlet diameters, weight | Bonney Forge's Branch Connections catalogue; every height checked against wermac.org's MSS SP-97 tables (all agree; where the base diameter differs, the manufacturer's is kept and the row says so) |
| `weights.csv` | Approximate empty weights (kg): butt-weld elbows (90° long and short radius, 45°), equal and reducing tees and reducers in standard weight (STD) and extra strong (XS); weld-neck and blind flanges, class 150 to 2500; flanged gate valves, class 150 to 600. Pipe is not listed: it is weighed from its diameter and wall (π (D − t) t ρ) | Fittings: a manufacturer's weights as tabulated on wermac.org (named on each row); reducing tees and XS reducers: Texas Flange's public tables. Flanges: wermac.org's weight chart (Texas Flange's figures). Gate valves: wermac.org's typical weights. Checks, on every row: the 73 reducers both sources list agree within 0.81–1.16; every elbow, tee and blind flange is compared with the weight of its own steel from the dimension tables (all within 0.7–1.45 except sizes of 1" and under, where published weights are rounded up); reducing tees weigh 0.5–1.25 × the equal tee; weights grow with size. Pipe weights agree with wermac.org's B36.10 weight table within 1.5 % |
| `classes/*.json` | Example pipe classes: CS1 (used by the examples), CS150, CS300, CS600, CS1500, LT150, SS150, UW150, each with material, ratings, schedules by size, the components it allows with their size ranges, and a branch table | Examples written for Datum Layout; not any company's class |

The reducing-tee and reducer tables were read from the catalogue pages in the app's own session (9 November 2026) and cross-checked row by row against a second table. The other tables were gathered in November 2026 with the help of an outside assistant working from manufacturers' public catalogues; every row was read by the app's checker and compared with the earlier tables before it was merged. No standard's tables or text are reproduced: the files hold dimensions only, as they appear in public catalogues, and are checked against those catalogues before 1.0 (roadmap). **Check every dimension against your supplier's data before ordering or building.**

## Plug-in packs

A pack is a folder (or a .zip of one) the user adds in the Catalogue panel. It may hold any of the files above with the same columns (its rows add to or replace the built-in rows of the same size and rating), and `classes/*.json` for more pipe classes. Every row needs a `source`. Rows that cannot be read are listed, and the rest of the pack is used.
