# Datum Layout 0.1.3: exchange verification

Run by `scripts/verify.sh` (also a CI job, "exchange"): every example is exported (`crates/core/examples/export.rs`), every line's piping component file is read by **Datum Pipe's own engine** (a fresh clone of `Edgar-Mendonca/Datum-Pipe`, its `import::pcf`), every free end is anchored and Pipe's stress analysis is run; every glTF file is checked by the **Khronos glTF validator** (`gltf-validator` 2.0.0-dev.3.10). Recorded 2026-11-03 with Datum Pipe at commit 47776fc.

The unit tests (`crates/core/src/exchange_tests.rs`) go further on Pipe's reader copied into this repository: the same nodes (to 0.02 mm), the same bend radii, tees, valves, flanges, strainers and reducers, and at least the same pipe length in each size.
